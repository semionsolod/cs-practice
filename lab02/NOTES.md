"Рабочая папка" Это место на моём пк, где хранятся все файлы проекта.
"Индекс" это промежуточная область, куда добавляются файлы с помощью git add.
"Коммит" сохранение состояния в git.
Git — это система контроля версий, которая работает локально на моём компьютере.
GitHub позволяет хранить копию репозитория в интернете, делиться кодом с другими людьми и работать в команде.
Команда `git diff`  показывает, какие изменения я сделал, но ещё не добавил в индекс.
Команда `git diff --staged`  показывает, какие изменения уже добавлены в индекс и попадут в следующий коммит.
`git status` — показывает текущее состояние репозитория
`git diff` — показывает различия между рабочей папкой и индексом.
`git diff --staged` — показывает различия между индексом и последним коммитом.
