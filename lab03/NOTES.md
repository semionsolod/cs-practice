git diff показывает изменения между рабочей директорией и индексом.
git show показывает полную информацию о конкретном коммите (автор, дата, сообщение и diff).
git log показывает историю коммитов.
-S"def" ищет коммиты, в которых менялось количество вхождений строки "def".
blame показывает, кто и в каком коммите последний раз менял каждую строку файла.
